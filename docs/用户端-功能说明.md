# 用户端功能说明

用户端是住客、商家、员工在手机或电脑网页里打开的那个应用。底部一直有三个按钮：**首页、订单、我的**。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

## 这个端是给谁用的

- **住客**：查酒店 / 民宿 / 钟点房、下单支付、看订单、到店核销、评价、会员与优惠券。
- **商家**：在「我的」申请入驻；审核通过后进入商家中心，管理门店、房间、订单、员工与商户钱包。
- **员工**：进入员工中心，协助到店核销、退房。
- **平台工作人员不使用这个应用。** 审商家、改系统配置、管全平台订单，在电脑上的管理端做。

## 登录与注册

常见方式：

- **验证码登录**：输入手机号，获取短信验证码后登录。
- **账号密码登录**：手机号 + 密码。
- **注册**：手机号 + 验证码 + 密码。
- **找回密码**：验证码重置密码。
- **微信登录**（小程序 / 微信内更常见）：需要后台已配置微信参数。登录后可能还要绑定手机号。

登录前需要勾选用户协议与隐私政策。

开发环境若开启短信模拟，验证码可直接填固定码（常见为 `123456`），不会真的发短信。

## 首页

打开就是首页。常见内容包括：

- 顶部可切换三类房源：**国内、钟点房、民宿**
- 选择目的地或「当前定位」
- 选择入住日期、离店日期（显示共几晚）
- 搜索酒店名称、地名或地标
- 点「查找房源」进入列表
- 轮播广告（可跳转到配置的内容）
- 热门推荐：封面、名称、评分、标签、地址、起步价，「预订」入口
- 下拉可刷新

首页数据来自服务端。服务端没启动或接口地址配错时，推荐列表会是空的或加载失败。

## 订酒店、订民宿、钟点房

### 看门店

- 门店图片、评分、标签、地址
- 可打开地图查看位置
- 用户点评列表
- 收藏、分享

### 选房下单

- 房型可按类型筛选
- 看到面积、剩余间数、原价与 **会员价（VIP）**
- 选入住 / 离店日期、房间数
- 从「常用信息」选择预订人姓名和手机号，也可先去添加、编辑入住人
- 下单时可选用优惠券
- 需要发票可勾选并填写抬头、税号等信息

### 付钱

下单后弹出支付窗口，常见可选：

- 钱包余额
- 微信支付
- 支付宝

具体显示哪些，取决于当前打开方式（H5 / 微信内）以及管理端是否配齐支付参数。没配密钥时，按钮可能点了没反应。

支付成功后订单生效；没付完可在订单里继续「支付」。

### 到店与取消

- 支付成功后，到店出示订单二维码或条形码办理入住；也可给商家打电话、看地图导航
- 订单状态大致包括：待支付、待核销、进行中、已完成、已取消
- 待支付取消一般不扣服务费；已支付的订单取消前会先提示是否产生费用，确认后再取消
- 入住完成后可打分、写评价

## 订单

底部第二个按钮。常见能力：

- 按状态筛选：全部、待付款、待核销、进行中、待点评、退款 / 售后等
- 列表上能区分这单是酒店还是民宿，并看到入住、离店日期和共几晚
- 待付款：取消或继续支付
- 待核销：打开详情出示二维码 / 条形码给前台
- 可看订单号、实付金额、优惠券抵扣、到店地址，联系商家，打开地图导航
- 完成后可评价

未登录进入订单时，一般会提示先登录。

## 我的

未登录时会引导「点击登录」。登录后常见内容：

### 上半部分

- 头像、昵称
- 会员中心入口（开通会员享专属权益）
- 优惠券、收藏、足迹数量
- 订单快捷入口：待付款、待出行、待点评、退款单、全部订单
- 钱包：全部资金、可用资金、可提现

### 更多服务

常见入口包括：

- 发票管理
- 优惠券 / 领券中心
- 邀请好友（推广）
- **商家入驻**（申请开店）
- 常用信息（入住人）
- 在线客服
- 帮助中心
- 意见反馈
- 设置（协议、退出登录、注销等）

## 会员中心

可查看套餐、权益说明并下单支付。常见权益包括专享折扣、身份标识、专属客服等（以后台配置为准）。订房时可见会员价。

## 钱包

- 查看余额与明细
- 充值（微信 / 支付宝，需配密钥）
- 提现、绑定收款方式（如支付宝账号或微信收款码）
- 提现申请提交后，需管理端审核；系统不会自动把钱打到你的微信或支付宝

## 商家能做什么

1. 在「我的」里点「商家入驻」，选择店铺类型（酒店或民宿）。
2. 填写店铺名称、电话，用地图点选门店真实位置，上传封面和轮播图，添加店铺标签，提交后看审核结果。审核被拒会显示拒绝原因。
3. 审核通过后进入商家中心：
   - 看今日、本月和总收益
   - 切换营业中或已打烊
   - 看待核销、已完成、已取消订单，看今日预订单，给住客打电话
   - 输入核销码或打开相机扫码，办理入住；住客离店时可完成退房
   - 房间：看上架中和已下架的房间，添加房间，管理已发布的房源
   - 员工：店主可添加员工、看员工列表
   - 商户钱包：看可提现收益，并按绑定的收款方式提现

## 员工能做什么

店主添加员工后，员工用自己的账号登录，进入员工中心，协助处理订单与到店核销（具体菜单以账号权限为准）。

演示账号（线上）：

| 角色 | 账号 | 密码 |
|---|---|---|
| 商家 | `18329680001` | `111111` |
| 员工 | `18329680002` | `123456` |

## 这个端真正会连到外面的服务

短信、微信、支付宝、图片存储、地图的密钥填在管理端「系统配置」中（或服务端环境配置），由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 你在页面上做的事 | 要申请的服务 | 官网 | 填在哪里 | 没填密钥时 |
|---|---|---|---|---|
| 注册、验证码登录、找回密码 | 短信服务商（短信宝 / 阿里云 / 腾讯云等） | https://cloud.tencent.com/product/sms 、 https://www.aliyun.com/product/sms | 管理端短信相关配置 | 验证码发不出去；开发模拟模式下可填固定验证码 |
| 微信登录 | 微信公众平台 | https://mp.weixin.qq.com/ | 管理端「登录认证」 | 提示微信登录暂未开通 |
| 订房 / 会员 / 充值微信支付 | 微信支付商户平台 | https://pay.weixin.qq.com/ | 管理端「支付配置」 | 无法拉起微信支付 |
| 订房 / 会员 / 充值支付宝 | 支付宝开放平台 | https://open.alipay.com/ | 管理端「支付配置」 | 无法拉起支付宝 |
| 头像、门店图、房间图上传 | 阿里云 OSS（或本地磁盘） | https://www.aliyun.com/product/oss | 管理端「文件存储」 | 上传失败或只能走本地路径 |
| 定位、选点、导航 | 地图开放平台 | 以你使用的地图服务为准 | 相关配置 / 前端地图 Key | 定位失败，可改手动选目的地 |

下面这些不用申请外面的 Key，服务端和数据库就绪就能用：

- 浏览库里已经有的门店与房型
- 下单流程界面（真正收款仍需支付配置）
- 订单列表状态查看、核销码展示（商家侧核销需登录商家 / 员工账号）
- 收藏、足迹、帮助文章、意见反馈（数据在自己库里）

下面这些看起来像外面的服务，但当前不会真的连出去自动完成：

- **提现**：只保存申请，等管理端审核后人工打款
- **分享海报 / 邀请链接**：生成分享内容，加好友仍是用户自己的动作
- **客服电话 / 企微**：按后台配置跳转或展示，不是系统自动外呼
