# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。住客、商家、员工日常订房不使用这个网站。它用来管酒店 / 民宿门店和用户、处理订单与财务，以及填写微信、支付、短信、图片存储这些外面服务的账号。

程序里的名称是「省钱兄民宿酒店预约系统」。工作人员登录后，左侧是菜单。能看到哪些菜单，由账号权限决定。没有权限的菜单不会出现。

下面的页面名称以当前后台侧栏与开源 SQL 菜单为准。如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

## 登录

登录页要填账号、密码，还要看一张图片验证码。看不清就点图片换一张。验证码由服务端生成。服务端没启动时，图片是裂的，登录也会失败。

开源包 SQL 已带演示管理员，可用：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

## 登录之后：数据中心

首页会展示运营概况，例如用户、订单、门店相关数字。数字来自自己的数据库。

## 用户中心

### 用户列表

查看注册用户账号。可进入详情查看资料、会员、钱包等相关信息。删除、改状态、改金额等敏感操作以实际按钮与权限为准。

### 注销信息

处理用户发起的账号注销申请。

## 酒店列表

维护平台上的酒店 / 民宿门店：

- 门店类型（酒店 / 民宿）、名称、电话、地址与地图位置
- 封面图、轮播图、标签、是否推荐、上下架与审核状态
- **房间管理**：房型、房间名称、封面与轮播、数量、价格、会员价、入住离店时间说明、设施分类、启用状态等

改完保存后，用户端下次打开首页 / 详情才会看到新内容。

## 商家入驻

审核用户端「商家入驻」提交的申请。可查看店铺资料，通过或驳回（驳回建议填写原因）。审核通过后，商家账号才能进入商家中心管自己的门店。

## 订单中心

查看平台住宿订单，跟踪待支付、待核销、进行中、已完成、取消 / 售后等状态，便于客服与运营排障。

## 财务中心

查看资金相关流水，以及转账、退款等操作入口（以页面实际按钮与权限为准）。提现类审核通过后，系统一般不会自动打款到微信 / 支付宝，仍需人工按收款信息处理。

## 会员与营销

### 会员配置 / 会员特权

配置用户端可购买的 VIP 套餐、价格与时长，以及权益说明文案。用户端会员中心会展示这些内容。

### 优惠券管理

配置优惠券、发放与领取记录。住客领券后可在下单时选用。

### 时间配置

与业务时间相关的配置项（以页面字段为准）。

### 推广中心

与邀请推广相关的后台配置 / 数据查看。

## 首页装修

维护用户端首页轮播等展示内容。改完保存后，用户端下次打开首页才会更新。

## 分类管理

维护房间设施 / 业务分类等选项，供房间编辑与展示使用。

## 帮助中心

维护用户端「帮助中心」里的分类与文章。

## 消息中心 / 评论中心 / 发票管理 / 聊天记录

- **消息中心**：给用户发站内消息（不是手机短信）。
- **评论中心**：查看住客对门店的评价。
- **发票管理**：查看用户开票相关申请 / 记录。
- **聊天记录**：查看客服相关会话记录（若已启用）。

## 系统配置

这是最重要的配置中心。外面服务的账号大多填在这里。常见能力包括：

| 配置项 | 用来做什么 |
|---|---|
| 基础配置 | 域名等基础项 |
| 登录认证 | 微信小程序 / 公众号等登录参数 |
| 支付配置 | 微信 / 支付宝商户参数 |
| 短信通道 / 短信模板 | 发验证码用哪家通道、模板内容 |
| 文件存储 | 本地目录或云存储（如阿里云 OSS） |
| 客服配置 | 电话 / 企微 / 个微二维码等展示方式 |
| 协议 CMS | 用户协议、隐私政策、关于我们等文案 |

改完要保存。用户端下次请求才会用新的密钥或文案。

## 系统管理

### 管理员列表 / 角色管理 / 菜单管理

决定谁能进后台、能点哪些页。

### 操作日志

查看工作人员在后台做过的重要操作，便于追责与排障。

## 和用户端怎么配合

管理端不自己保存住客的订房结果。它把操作发给服务端，服务端再写入数据库。所以：

- 服务端没启动时，验证码出不来，登录会失败。
- 在这里改完门店、房间、会员 / 优惠券并保存后，用户端下次打开才会看到。
- 外面的密钥只配在「系统配置」（或服务端环境相关配置）里。用户端没有地方填写微信支付商户号。
- 商家在用户端提交入驻后，需要你在「商家入驻」里审核，商家才能管自己的店。
