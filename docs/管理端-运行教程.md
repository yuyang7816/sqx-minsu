# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `jdms-admin` 文件夹。程序名称是「省钱兄民宿酒店预约系统」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「酒店民宿项目启动成功」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 **Node.js 20 或更高**（见 `jdms-admin/package.json` 的 `engines`，要求类似 `^20.19.0 || >=22.12.0`）：https://nodejs.org/

安装时勾选添加到 PATH。安装完成后，重新打开终端，输入：

```bash
node -v
npm -v
```

应看到 `v20.x` 或更高，以及可用的 npm。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

管理端通过 `jdms-admin/comment/httpUrl.js` 决定请求发到哪里。

仓库里可能默认指向线上：

```javascript
const ROOTPATH = "https://jdmsadmin.xianmaxiong.com/sqx_fast";
```

本地联调请改成你的本机服务端，例如：

```javascript
const ROOTPATH = "http://127.0.0.1:9129/sqx_fast";
```

说明：

- 端口必须与服务端一致，默认是 **9129**
- 路径必须带 **`/sqx_fast`**
- 改完后如果网站已经在运行，要先停掉再启动，修改才会生效

部分上传组件里可能写死了线上上传地址（如 `https://jdmsadmin.xianmaxiong.com/sqx_fast/alioss/upload`）。本地上传图片时，若上传失败，把这些地址也改成本机：`http://127.0.0.1:9129/sqx_fast/alioss/upload`。

## 第 2 步：安装依赖

仓库**不包含** `node_modules`。在 `jdms-admin` 文件夹里打开终端，执行：

```bash
cd jdms-admin
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `jdms-admin` 文件夹里执行：

```bash
npm run dev
```

窗口里会出现本地地址。默认端口是 **8888**（见 `vite.config.js`）。没有自动打开时，手动打开：

http://localhost:8888

登录页上应能看到「省钱兄民宿酒店预约系统」字样，以及一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个终端窗口也要一直开着。

## 怎样算成功

使用数据库里的管理员登录（见 [服务端运行教程](服务端-运行教程.md)）：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |
| 验证码 | 登录页图片上的字符 |

登录成功后进入「数据中心」。左侧应能看到菜单，例如：

- 数据中心、用户中心、财务中心、订单中心
- 酒店列表、商家入驻、首页装修
- 会员配置、会员特权、优惠券管理
- 帮助中心、消息中心、评论中心、发票管理
- 系统配置、系统管理（管理员 / 角色 / 菜单）等

开源 SQL 已带菜单与管理员数据。若你自己清空了权限表，侧栏可能变空，需要重新导入或在「菜单管理 / 角色管理」中恢复。

酒店列表里有演示门店不代表后台「连错了」；库本来就有演示数据。要试用支付、短信、微信登录，还需在「系统配置」填写对应密钥。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开终端。

**`npm ERR!` 或引擎版本不符合**  
`node -v` 过低。安装 Node 20+ 后再执行 `npm install`。

**浏览器打不开 localhost:8888**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `comment/httpUrl.js` 不是你的本机服务端。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求应走到 `127.0.0.1:9129`（或你改过的地址），不应误发到错误域名。改完地址后，在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 8888 is in use`**  
8888 已被占用。关掉之前的管理端窗口再启动，或改 `vite.config.js` 里的 `server.port`。

**登录提示验证码不正确**  
图片上的字要和输入完全一致。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。

**能登录但左侧几乎没有菜单**  
检查当前账号角色权限，或重新导入 `jdms-server/db/jdms.sql` 后的菜单 / 角色数据。

**改了系统配置 / 酒店信息，用户端没变化**  
确认已经点保存；用户端需要重新打开页面或重新请求接口。服务端窗口必须还在运行。

**本地上传图片失败**  
检查上传接口是否仍指向线上域名；改成本机 `alioss/upload` 地址，并确认服务端文件目录可写。
