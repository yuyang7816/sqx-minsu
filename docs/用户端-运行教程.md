# 用户端运行教程

按顺序做。这是给住客、商家、员工用的手机 / 网页应用。推荐用 HBuilderX 打开 `jdms-uniapp` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `jdms-server/db/jdms.sql` 并启动服务端。首页房源、订单、登录的数据都来自这个服务。服务端没启动时，页面也许能打开，但登录会失败，列表也可能是空的。

开源 SQL 通常带有演示门店。C 端用户可自行注册；演示商家 / 员工账号见文末「线上演示」。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

如果组件样式异常，还需要安装 **Node.js**（建议 18+），并在 `jdms-uniapp` 目录执行一次 `npm install`（会安装 `uview-ui` 等依赖）。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `jdms-uniapp/common/config.js`。仓库默认可能是别的线上地址，例如：

```javascript
const ROOTPATH = "https://某某域名/sqx_fast";
```

本地联调请改成你的本机服务端，例如：

```javascript
const ROOTPATH = "http://127.0.0.1:9129/sqx_fast";
const ROOTPATH1 = "http://127.0.0.1:9129/sqx_fast";
const ROOTPATH2 = "ws://127.0.0.1:9129/sqx_fast/websocket/";
const ROOTPATH3 = "ws://127.0.0.1:9129/sqx_fast/chatSocket/";
const ROOTPATH4 = "http://127.0.0.1:9129/sqx_fast";
```

请确认端口与服务端 `application.yml` 的 **9129** 一致，路径带 **`/sqx_fast`**。

真机调试时，把 `127.0.0.1` 换成你电脑的局域网 IP（例如 `192.168.0.109`），并保证手机和电脑在同一网段。

若只想先体验界面、暂时不跑本机服务端，也可改成线上演示：

```javascript
const ROOTPATH = "https://jdms.xianmaxiong.com/sqx_fast";
```

改完后要重新运行一次，修改才会生效。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `jdms-uniapp` 这个文件夹。不要选它的上一级（那一层还有 `jdms-server` 和 `jdms-admin`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`、`static` 等。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址以控制台里打印的为准。
4. 打开后底部应能看到三个入口：**首页、订单、我的**。
5. 若浏览器问能不能获取位置，点「允许」，首页才能按当前位置找房；也可以手动选目的地。

HBuilderX 不要关。关掉后页面会打不开。

如果 uView 样式花屏、组件报错，在 `jdms-uniapp` 目录执行：

```bash
npm install
```

然后再重新运行一次。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里小程序 `appid` 若仍是原项目号码，你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成你自己的小程序 AppID，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 怎样算成功

1. 能打开首页，看到「国内 / 钟点房 / 民宿」切换、「查找房源」和热门推荐。
2. 底部三个按钮能点：**首页、订单、我的**。
3. 点「我的」能看到登录入口、会员、商家入驻等。
4. 按键盘 `F12`，点「网络」或 Network，再刷新。列表里的请求地址应是你在第 1 步配置的地址。仍出现非预期域名，说明第 1 步没有保存，或改完后没有重新运行。

### 本地如何登录

1. 打开「我的」→「点击登录」，或按页面引导进入登录。
2. 勾选用户协议与隐私政策（未勾选通常无法继续）。
3. **密码登录**：输入手机号 + 密码。
4. **验证码登录**：获取验证码。若服务端开启短信模拟，按后台说明填写固定验证码（常见为 `123456`）；未开模拟则需配置真实短信。
5. 也可先「注册账号」再建账号。

### 建议验收路径（给不懂代码的人）

1. 首页切换「民宿」，点「查找房源」或点某个热门酒店「预订」。
2. 进入房型列表，能看到价格与「预订」按钮。
3. 登录后进「订单」，能看到订单状态筛选。
4. 用商家账号登录，在「我的」里找到商家相关入口（商家中心），能看待核销等能力。
5. 用员工账号登录，能进入员工中心协助核销（以账号权限为准）。

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `jdms-uniapp`。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字保留下来。常见原因是打开的文件夹不是 `jdms-uniapp`，或编译器还没下完，或缺少 `npm install`。

**首页能开，但登录失败 / 接口报错**  
服务端没有启动，或 `jdms-uniapp/common/config.js` 仍是错误地址 / 错误端口。先看服务端窗口是否还有「酒店民宿项目启动成功」，再改第 1 步为 **9129**，然后重新运行。

**地图不显示或定位失败**  
需要允许浏览器使用位置。学习看页面时可以先手动选一个目的地。

**收不到短信验证码**  
本地若开启模拟短信，请填固定验证码。正式环境需要管理端配置真实短信通道。

**微信支付、支付宝点了没反应**  
需要自己的支付商户参数。开源代码一般只能看到支付按钮，不能真的完成收款，除非你配齐密钥。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。

**真机预览接口失败**  
不要用 `127.0.0.1`（那是手机自己）。改成电脑局域网 IP，并检查电脑防火墙是否放行 9129 端口。
