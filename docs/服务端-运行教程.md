# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。代码在 `jdms-server` 文件夹。数据库脚本在：`jdms-server/db/jdms.sql`（含表结构，以及管理员、菜单、演示门店与房间等数据）。

可以把它理解成「总台」：管理端和用户端把登录、查房、下单、支付、核销、商家入驻这些请求发给它；它检查是否允许，把结果存进数据库，必要时再去问短信、微信、支付、地图这些外面的服务。

## 开始之前要准备什么

在自己的电脑上安装下面四个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 终端输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 8.0（5.7 一般也可） | 能连上本机 MySQL，端口一般是 **3306** |
| Redis | 5.0 或更高 | 输入 `redis-cli ping`，应返回 `PONG` |

Java 不要装成 11、17 或 21。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的终端，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root` 设一个密码，还会让你确认端口。把密码和端口记下来。

本项目启动时会连接 Redis（登录态、系统配置缓存等都要用）。启动前必须先开 Redis。开发配置默认地址 `localhost:6379`，密码为空，数据库编号为 `5`。若你给 Redis 设了密码，同步改 `application-dev.yml` 里的 `redisson.password`。

## 第 1 步：新建空数据库

这份 SQL 文件会建表并写入演示数据，但不会自己创建名叫 `jdms` 的库。要先建库，再导入。

1. 打开 MySQL 命令行或客户端，登录。
2. 执行：

```sql
CREATE DATABASE IF NOT EXISTS jdms DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

3. 再执行：

```sql
SHOW DATABASES;
```

列表里有 `jdms` 就成功了。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`jdms-server/db/jdms.sql`

这份脚本里包含：

- 全部业务表（门店、房间、订单、用户、会员、优惠券、发票等）
- 管理端账号 `admin` / `123456`
- 后台菜单与角色（数据中心、酒店列表、订单中心、商家入驻、系统配置等）
- 演示用的门店、房间、轮播等内容（以脚本实际数据为准）

导入会覆盖同名的表，所以请导入到上一步新建的空库，不要导入到别的业务库。

### macOS / Linux 示例

把密码、端口改成你的 MySQL：

```bash
mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 jdms < jdms-server/db/jdms.sql
```

### Windows PowerShell 示例

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 jdms -e "source $($PWD.Path -replace '\\','/')/jdms-server/db/jdms.sql"
```

执行结束时没有 `ERROR`，再执行下面这句，能看到很多表名（含 `sys_user`、`sys_menu`、`shops`、`shops_room`、`orders`、`tb_user` 等），就说明导入成功：

```bash
mysql -uroot -p你的密码 -P3306 -e "USE jdms; SHOW TABLES;"
```

用 Navicat 也可以：连接到本机 MySQL，双击打开 `jdms`，菜单选「运行 SQL 文件」，选中 `jdms-server/db/jdms.sql`，编码选 UTF-8，点开始。

## 第 3 步：确认管理员账号

导入成功后，管理端默认账号已经在库里：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

登录管理端时还要输入图片验证码（由服务端生成）。

如果以后忘记密码，需要按项目规则用「密码 + 盐」重新生成哈希再写回 `sys_user` 表；初学者直接重新导入 SQL 最省事。

## 第 4 步：让程序连接你自己的 MySQL

打开 `jdms-server/sqx-application/src/main/resources/application.yml`，找到：

```yaml
spring:
  profiles:
    active: prod
```

本地练习请改成：

```yaml
spring:
  profiles:
    active: dev
```

这样会读取 `application-dev.yml`。

打开 `jdms-server/sqx-application/src/main/resources/application-dev.yml`，把数据库地址、账号密码改成你的：

```yaml
url: jdbc:mysql://127.0.0.1:3306/jdms?useUnicode=true&characterEncoding=utf-8&useSSL=false&allowPublicKeyRetrieval=true
username: 用户名
password: 密码
```

把上面的 `用户名`、`密码` 换成你的 MySQL 账号密码；端口不是 3306 时一并改 URL。**库名保持 `jdms`**（与第 1 步新建的库一致）。

仓库里的开发配置可能写着别的主机或旧库名，本地联调时务必改成你自己电脑上的 MySQL。

## 第 5 步：启动 Redis

本机启动 Redis，并确认：

```bash
redis-cli ping
```

返回 `PONG` 再继续。

`application-dev.yml` 里默认大致是：

| 项 | 默认值 |
|---|---|
| host | `127.0.0.1` |
| port | `6379` |
| password | 空 |
| database | `5` |

若你改过 Redis 密码或端口，请同步改 yml。

## 第 6 步：启动服务端

在 `jdms-server` 文件夹里打开终端，执行：

```bash
mvn clean package -DskipTests
cd sqx-application
mvn spring-boot:run
```

或者打包后直接运行：

```bash
mvn clean package -DskipTests
java -jar sqx-application/target/*.jar --spring.profiles.active=dev
```

第一次会下载很多依赖，可能要 10 到 30 分钟，窗口要一直开着。看到类似下面的字才算启动成功：

```text
酒店民宿项目启动成功
```

以及 Spring Boot 常见的 `Started SqxApplication`。

不要关闭这个窗口。关闭后服务端就停了。

用 IDEA 也可以：

1. 用 IDEA 打开 `jdms-server`（选有根 `pom.xml` 的那一层）。
2. 等右下角 Maven 导入结束。Project SDK 选 1.8。
3. 菜单「File」→「Settings」→「Plugins」，搜索并安装 Lombok，然后勾选「Enable annotation processing」。
4. 打开 `sqx-application/src/main/java/com/sqx/SqxApplication.java`，确认 Active profiles 为 `dev`，点左侧绿色三角。
5. 控制台同样要出现「酒店民宿项目启动成功」。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9129/sqx_fast/doc.html

能看到 Knife4j 接口文档（标题类似「酒店民宿系统接口文档」）。如果这个页面打不开，只要启动日志里有「酒店民宿项目启动成功」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

服务端默认：

| 项目 | 值 |
|---|---|
| 端口 | `9129` |
| 接口前缀 | `/sqx_fast` |
| 接口文档 | `http://127.0.0.1:9129/sqx_fast/doc.html` |

短信、微信、支付宝、图片存储、地图这些密钥需要自己到对应官网申请，再填进管理端「系统配置」各页签。用途说明见 [服务端功能说明](服务端-功能说明.md) 与 [用户端功能说明](用户端-功能说明.md)。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
Java 没装好，或装成了更高版本。安装 Temurin 8，关掉终端再打开，重新执行 `java -version`。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 没有加到 PATH。加完后必须关掉终端再开一次。

**`Access denied for user 'root'`**  
MySQL 密码和 yml 里的 `password` 不一致。把 yml 里的密码改成你安装时设的密码。

**`Communications link failure`**  
本机 MySQL 没有监听配置里的主机/端口。核对 URL 后重启服务端。

**`Unknown database 'jdms'`**  
第 1 步的建库没有成功。回到命令行把 `CREATE DATABASE` 再执行一次。

**导入 SQL 时中文变问号**  
命令里要带 `--default-character-set=utf8mb4`。用 Navicat 时，运行 SQL 文件的编码选 UTF-8。

**启动报 Redis / Redisson 相关错误**  
先启动 Redis。密码、端口、库号与 `application-dev.yml` 里的 `redisson` 配置保持一致。

**`Port 9129 was already in use`**  
9129 端口已经被占用。把之前开着的服务端窗口关掉，或结束对应的 Java 进程，然后再启动。

**管理端验证码图片是裂的**  
服务端没启动，或管理端连的不是 `http://127.0.0.1:9129/sqx_fast`。

**用户端收不到短信验证码**  
若管理端 / 服务端开启了短信模拟，请按配置使用固定验证码（常见为 `123456`）。正式发短信需要配置真实短信通道。

**用户端支付 / 微信登录提示失败**  
管理端「系统配置」里的支付、登录认证未填写密钥，或服务端访问不了对应厂商接口。浏览房源、看订单列表等基础功能仍可本地联调。
